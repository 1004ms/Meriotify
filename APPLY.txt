Meriotify installer/uninstaller hardening patch

Replace these files in the repository root:
- install.ps1
- uninstall.ps1

Fixes:
- uninstall now removes Meriotify from both persisted and current-session PATH
- uninstall verifies install/data folders are actually deleted before printing OK
- uninstall retries folder deletion and reports real failure instead of silently succeeding
- installer resolves the exact release asset from GitHub release metadata
- installer executes Meriotify config/setup commands with all arguments correctly
- installer reports the exact failing command/error
- installer rolls back a partial installation instead of leaving meriotify.exe installed after failure
