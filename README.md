<h1 align="center">Meriotify</h1>
<p align="center"><b>Spotify, your way.</b></p>

Meriotify customizes Spotify and includes Marketplace in one clean install.

## Install

Open PowerShell normally and run:

```powershell
irm https://github.com/1004ms/Meriotify/releases/latest/download/install.ps1 | iex
```

Choose your language. Meriotify + Marketplace are installed and Spotify is configured automatically.

## Update

```powershell
meriotify update
```

## Uninstall

```powershell
irm https://github.com/1004ms/Meriotify/releases/latest/download/uninstall.ps1 | iex
```

## Compatibility

Meriotify keeps the compatibility layer required by existing Spotify themes, extensions and Marketplace packages.
